# What can be checked from this repository

The scripts follow the methods recorded for the study. The original source
files were unavailable, so these scripts should not be cited as exact copies.
The values in `data/frozen_results.json` are transcribed from the study record,
not recalculated here.

The provenance table gives an arithmetic reference. If a required field is
retained in a fraction `r` of records, the single-field reference is `r`.
Checking both members of a duplicate pair requires two retained hashes, so
the pair reference is `r²`. These values concern available provenance, not
changes in model accuracy.

The controlled-corruption and near-duplicate tables list test settings and
theoretical outcomes. They do not contain measured detection rates. Rechecking
the reported clinical results requires the non-public manifest and source
imaging.

# Reproducibility record
The archive separates (1) frozen reported study results from (2) reconstructed executable implementations.
The provenance-stress reference is analytic: if a required field is retained with fraction r, a single-field audit reference is r and an exact duplicate-pair equality reference requiring two hashes is r^2. This describes an auditability ceiling, not model-performance degradation.
Controlled corruption and near-duplicate files document illustrative
regression/stress-test parameters and analytic oracle values. They do not
report observed detection rates or clinical effect estimates. The supplied
aggregate study facts cannot be independently recomputed without the
non-public clinical manifest and source imaging.
